# HDL Coder

Esta carpeta agrupa el material base para un tutorial de HDL Coder dentro del proyecto.
La idea es ir agregando guias, ejemplos y recursos de forma incremental; por ahora se deja
aqui una introduccion minima y la estructura se ira completando en siguientes iteraciones.

## Contenido inicial
- `Docs/`: documentos y guias de referencia para HDL Coder.

## Alcance previsto
- Flujo basico de generacion de HDL desde MATLAB/Simulink.
- Buenas practicas y configuraciones recomendadas.
- Ejemplos simples con resultados reproducibles.
